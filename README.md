## 👋 About Me

Senior Backend Engineer with **7+ years** in Java / Kotlin, based in Taipei, Taiwan. I engineer and maintain enterprise-scale **Billing & Payment** systems and serve as first-line support for their production issues. I also bring hands-on **SRE & Cloud** skills and build **LLM-powered developer tooling**.

- **Backend:** Java, Kotlin, Spring Boot, MySQL (SQL performance tuning), Python, JavaScript / TypeScript; also interested in Go.
- **SRE & Cloud:** AWS, Docker, Kubernetes, Linux, Prometheus, Grafana — and always leveling up.
- **LLM tooling:** Claude Code / Codex plugins, MCP servers, persistent dev memory — see below.
- **Also:** 3+ years of React / Vue frontend exposure and about 8 months of Android development.

Pleased to meet you!
